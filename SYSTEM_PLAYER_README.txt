ZIH 本地云盘｜系统播放器模式

为什么需要这个助手？
浏览器（包括 Chrome）只能播放它支持的编码。如果本地视频是某些 MKV/AVI/HEVC/DTS 等组合，网页播放器可能出现 0:00 或黑屏。
本助手不让 Chrome 解码，而是把本地文件直接交给 Windows 的默认播放器。

使用方法：
1. 双击「启动系统播放器助手.bat」。
2. 第一次运行时选择你的本地云盘文件夹。
3. 打开 ZIH 博客 → 预览 → 云盘 → 扫描视频/图片。
4. 点开一个本地视频，在播放器右上角点击「🖥️ 系统播放器」。
5. Windows 会用该视频文件默认关联的播放器打开它。

安全说明：
- 助手只监听 127.0.0.1:47823，只接受本机请求。
- 只能打开你启动助手时选择的根文件夹及其子文件夹。
- 不上传视频，不经过网站服务器。
- 关闭 PowerShell/助手窗口即可停止服务。

注意：
Windows 自带的播放器本身也可能不支持某些编码。若系统播放器也打不开，则需要安装支持更多编码的播放器（例如 VLC）或转换视频格式。
