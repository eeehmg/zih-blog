# ZIH Blog / GitHub Pages 版

本版本基于原 ZIP 增加了三个可串联页面：

- `login.html`：登录 / 注册
- `index.html`：原有内容网站
- `admin.html`：后台管理入口

## GitHub Pages
将整个项目上传到 GitHub 仓库，在 Settings → Pages 中选择从主分支发布。

## 当前登录机制
这是纯静态 GitHub Pages 版本，账号数据使用浏览器 `localStorage` 保存。
它适合个人网站原型和演示，不适合作为真正的生产级账号系统。

## 管理员
注册用户名为 `admin` 时会创建管理员角色，可从内容页进入后台（具体入口可继续接入到现有导航）。

下一阶段可以接入真实的免费/免费额度后端与数据库，实现跨设备账号、评论、收藏、消息、群聊、云盘等。

## 本次升级修复
- 根地址自动进入登录页，登录后返回原页面。
- 电脑顶部「预览 / 个人 / 关于 / 友链」和手机底部对应按钮统一修复。
- 右下角齿轮设置面板增加独立点击兜底。
- 管理员登录后品牌区显示「后台」入口。

## V3 修复
- 默认隐藏右下角向上箭头、评论、图片三个固定按钮，只保留 ⚙️ 设置。
- 手机端底部导航提高可点击区域并避开安全区。
- V4 已改为网页播放助手：不需要 BAT、PowerShell、127.0.0.1 或 Windows 本机播放器助手，手机 / 电脑直接在浏览器播放。


### V4 直连播放

在“预览”中点击已上传的视频卡片，会直接使用“网页播放助手”播放，不再先进入旧的媒体预览弹窗，也不需要再点一次“网页播放助手”。

网页播放助手完全运行在浏览器中，不依赖 BAT、PowerShell、VLC、PotPlayer 或 127.0.0.1 本机服务。
