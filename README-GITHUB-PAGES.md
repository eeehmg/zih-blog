# ZIH Blog / GitHub Pages 版

本版本基于原 ZIP 增加了三个可串联页面：

- `login.html`：登录 / 注册
- `index.html`：原有内容网站
- `admin.html`：后台管理入口

## GitHub Pages
将整个项目上传到 GitHub 仓库，在 Settings → Pages 中选择从主分支发布。

## 当前登录机制
这是纯静态 GitHub Pages 版本，账号数据使用浏览器 `localStorage` 保存。
它适合个人网站原型和演示，不适合作为真正的生产级账号系统。

## 管理员
注册用户名为 `admin` 时会创建管理员角色，可从内容页进入后台（具体入口可继续接入到现有导航）。

下一阶段可以接入真实的免费/免费额度后端与数据库，实现跨设备账号、评论、收藏、消息、群聊、云盘等。

## 本次升级修复
