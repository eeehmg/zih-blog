assets 目录说明（头像 / 联系方式照片 / 音乐）
========================================

请把文件按下面结构放置：

assets/
├── avatar/
│   └── avatar.png          ← 默认头像（推荐正方形，建议 ≤ 512×512）
├── contacts/
│   ├── wechat.png          ← 微信二维码/照片
│   └── douyin.png          ← 抖音二维码/照片
├── music/
│   └── bgm.mp3             ← 默认背景音乐（mp3 / m4a / ogg 均可）
└── gallery/                ← 相册示例图（可选）

使用方式：
1. 把图片/音频文件放进对应文件夹
2. 刷新页面即可看到默认资源
3. 用户在页面上「点击上传」后，会覆盖到浏览器 localStorage（仅本机有效）
4. 想永久生效 → 把文件放到 assets 并保持文件名一致，或修改 js/app.js 里的默认路径

注意：GitHub Pages 是静态托管，浏览器无法把上传的文件真正写入仓库。
      上传功能只保存在当前浏览器的 localStorage 里。
      正式发布请把图片/音乐预先放到 assets 文件夹再提交。
