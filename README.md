# ZIH · 博客小栈

个人博客，支持文章/新闻发布、相册、留言、联系方式、音乐播放、主题切换、数据导入导出。

## 部署到 GitHub Pages

1. 新建仓库，例如 `zih-blog`
2. 将本文件夹内容上传到仓库根目录（或 `docs/` 目录）
3. 在仓库 Settings → Pages → Source 选择 `main` 分支 / root（或 docs）
4. 等待几分钟即可访问 `https://<username>.github.io/zih-blog/`

## 头像 / 联系方式照片 / 音乐（已放到 assets）

把文件按上面路径放入即可，刷新页面自动加载：

| 类型 | 路径 | 说明 |
|------|------|------|
| 头像 | `assets/avatar/avatar.png` | 侧边栏默认头像 |
| 微信 | `assets/contacts/wechat.png` | 联系方式卡片图片 |
| 抖音 | `assets/contacts/douyin.png` | 联系方式卡片图片 |
| 音乐 | `assets/music/bgm.mp3` | 侧边栏默认背景音乐 |

- 页面上「点击上传」仍会保存到浏览器 localStorage（仅本机有效）。
- GitHub Pages 是静态站，无法把浏览器上传的文件真正写进仓库。
- **正式发布请把图片/音乐预先放到 assets 再提交**，这样所有访客都能看到。

其他数据（文章、评论等）仍在 localStorage，支持导出 JSON 备份。

## 预览（图片 + 视频）

- 支持上传图片与视频（预览页「上传图片 / 上传视频」）
- 视频可在线播放（`<video controls>`）
- 单文件建议 ≤ 4MB（受浏览器 localStorage 限制）
- 大视频请放到 `assets/gallery/` 再引用
- 支持添加云盘分享链接（预览页「☁️ 添加云盘」）：粘贴百度网盘/阿里云盘/夸克网盘等分享链接和提取码即可，不占用本机存储空间；点开卡片会显示「打开云盘链接」和「复制提取码」按钮（网盘一般不允许被 iframe 嵌入，所以是跳转打开而不是站内播放）

## 搜索功能

- 点击顶部 **搜索图标** 打开搜索栏
- 支持按 **标题 / 分类 / 摘要 / 正文** 实时过滤
- 与当前分类筛选叠加（例如：先选「英语体系」，再搜关键词）
- `Esc` 清空或关闭搜索栏，点 ✕ 清除关键词

## 本地云盘功能

预览页的「云盘」现在支持连接电脑上的本地文件夹。首次使用：
1. 打开「预览」→「☁️ 云盘」→「📁 选择文件夹」。
2. 选择一个文件夹；如果该文件夹本身是 OneDrive、Google Drive、Dropbox 等桌面同步盘的文件夹，文件会由对应客户端继续同步。
3. 连接后点击「上传图片」或「上传视频」，文件会优先复制到已连接的本地云盘文件夹，并在预览中显示。
4. 连接信息会保存在浏览器的 IndexedDB 中，刷新页面后可继续使用；如果浏览器要求重新授权，请重新连接文件夹。

注意：本功能使用浏览器 File System Access API，推荐在最新版 Chrome / Edge 的电脑端，并通过 HTTPS 或 localhost 运行。普通 HTTP 非安全环境可能无法调用文件夹选择器。浏览器无法绕过系统权限，也不能让网站后台静默读取任意电脑文件夹。

## V4 网页播放助手

V4 已移除 Windows 本机播放器助手。网站现在提供「🎬 网页播放助手」，可在浏览器内直接播放本地选择的视频/音频、远程媒体直链以及本地云盘扫描到的可解码媒体。

注意：浏览器仍然受自身解码能力限制，MKV/AVI/FLV 等容器或某些编码可能无法直接播放；最稳妥的网页格式是 MP4（H.264 + AAC）或 WebM。


## V4.1：上传视频与网页播放助手合并
- 点击「🎬 上传并播放视频」选择视频。
- 视频保存完成后自动打开网页播放助手并开始播放。
- 不需要 Windows `.bat`、PowerShell、VLC/PotPlayer 或 127.0.0.1 本机助手。
